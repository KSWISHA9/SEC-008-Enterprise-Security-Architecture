Green labeled paths are permitted/observed; the red labeled path ends at the firewall and is denied, not a successful connection. The dotted DNS path is a separate investigation. Local application authentication is not integrated with the domain controller. The Kali source address is specified by the UFW rule; a separate Kali IP inventory capture is missing. ICMP remains reachable from Windows in the negative application tests; denying TCP 8080 does not mean all Windows traffic is blocked.

## Threat Model and Scope

Tests cover a non-approved Windows source, approved-path requests with missing/invalid/valid credentials, and a controlled application outage. An approved IP does not establish user or device trust. Valid local credentials grant content, but enterprise role policy, MFA, device posture, credential lifecycle and brute-force protections are not demonstrated. A compromised approved client or stolen valid credentials remain risks.

Basic authentication does not encrypt credentials. TLS is required before using this pattern beyond the isolated training context. See [RFC 7617, security considerations](https://www.rfc-editor.org/rfc/rfc7617.html#section-4).

The project demonstrates **host-based microsegmentation and local application authentication, not complete enterprise Zero Trust**. NIST's model does not infer trust from network location and addresses subject/device authentication and authorization. This lab does not implement that full model. See [NIST SP 800-207](https://csrc.nist.gov/pubs/sp/800/207/final).

## Persistence and Evidence Limits

SEG-08 shows runtime interfaces, not an exported persistent network configuration. SEG-09 shows service enablement/active status and HTTP 200 but a blank immediate listener query. SEG-10 shows a listener and operational state for the earlier application; AUTH-01's journal boot boundary corroborates historical startup chronology. Paired boot checks and remote positive/negative persistence tests for the authenticated deployment remain missing. Recovery stop/start tests do not substitute for them.

The full systemd unit, network configuration and authentication implementation were not exported or inspected. Historical root-level filenames are not independent topology assertions: SECX001-02-DC-NAT-Adapter.png actually displays the host-only second adapter. DNS captures and root-level baseline images remain preserved for context.
