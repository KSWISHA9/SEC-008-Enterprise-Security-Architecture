# Project Naming

SECX-001 was renamed locally to **SEC-008 - Enterprise Security Architecture & Zero Trust** on October 10, 2026. Its separate public repository is [SEC-008-Enterprise-Security-Architecture](https://github.com/KSWISHA9/SEC-008-Enterprise-Security-Architecture).

SECX-002 is now the separate [SEC-009 GRC/CMMC assessment](https://github.com/KSWISHA9/SEC-009-Enterprise-GRC-CMMC-Readiness). Existing SEC-001 SOC and SEC-002 vulnerability-management repositories are unchanged.

Screenshot filenames, source provenance, VM commands/service identifiers and historical snapshots keep their original names. Renaming does not change test results or close findings. The complete pre-rename copy remains preserved outside this repository in the local Codex review workspace.

The original SecurityX learning-track labels remain planning context; the future integrated capstone is not this architecture repository. See the [release record](Reports/Release-Record.md) for the publication scope.
